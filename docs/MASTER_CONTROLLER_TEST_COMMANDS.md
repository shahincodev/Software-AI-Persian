# 🧪 دستورات تست Master AI Controller

این فایل شامل دستورات آماده برای تست Master Controller است.

---

## 🚀 نحوه اجرا

### روش 1: تست کامل خودکار
```bash
python tests/test_master_controller_complete.py
```

### روش 2: تست دستی با main.py
```bash
python main.py --enable-automation
```

---

## 📝 دستورات تست آماده

### دسته 1️⃣: CHAT - گفتگو

```
سلام، حالت چطوره؟
هوش مصنوعی چیست؟
تفاوت Python و JavaScript چیه؟
Machine Learning رو توضیح بده
چطوری برنامه‌نویسی یاد بگیرم؟
What is artificial intelligence?
```

**انتظار**: باید به ToolType.CHAT هدایت شود

---

### دسته 2️⃣: SYSTEM - اطلاعات سیستم

```
CPU چقدره؟
چقدر RAM آزاد دارم؟
فضای دیسک چقدر باقی مونده؟
وضعیت سیستم من چطوره؟
CPU من چند هسته داره؟
How much memory am I using?
اطلاعات کامل سیستم
```

**انتظار**: باید به ToolType.SYSTEM هدایت شود
**نتیجه**: پاسخ انسانی مثل "پردازنده شما ۴۵٪ مشغول است..."

---

### دسته 3️⃣: DESKTOP - کنترل دسکتاپ

```
باز کن notepad
اجرا کن Calculator
باز کن This PC
مرورگر کروم رو باز کن
open notepad
launch Calculator
```

**انتظار**: باید به ToolType.DESKTOP هدایت شود
**نتیجه**: برنامه مورد نظر باز می‌شود

⚠️ **توجه**: این دستورات واقعاً برنامه‌ها را اجرا می‌کنند!

---

### دسته 4️⃣: BROWSER - جستجوی وب

```
هوا امروز چطوره؟
قیمت دلار چقدره؟
آخرین اخبار تهران
what's the weather today?
Bitcoin price
```

**انتظار**: باید به ToolType.BROWSER هدایت شود
**وضعیت**: 🚧 در حال توسعه (ممکن است به CHAT هدایت شود)

---

### دسته 5️⃣: موارد ترکیبی

```
نوت‌پد
Chrome
میشه نوت‌پد رو باز کنی؟
باز کن Calculator
```

**انتظار**: باید درخواست را درست تشخیص دهد

---

### دسته 6️⃣: Edge Cases

```
(رشته خالی)
   (فقط فاصله)

12345

```

**انتظار**: باید به CHAT هدایت شود و خطا ندهد

### زمان اجرا

- ✅ باید به زبان درخواست کاربر باشد (فارسی/انگلیسی)
- ✅ باید ساده و قابل فهم باشد
- ✅ نباید JSON یا خروجی فنی نشان دهد

## 🐛 چک‌لیست عیب‌یابی

اگر تست‌ها کار نکردند:

### ✅ چک کردن API Keys
```bash
# فایل .env را بررسی کنید
GOOGLE_API_KEY=your_key_here
OPENAI_API_KEY=your_key_here
GROQ_API_KEY=your_key_here
```

### ✅ چک کردن Dependencies
```bash
pip install -r requirements.txt
```

### ✅ چک کردن Python Version
```bash
python --version
# باید Python 3.8+ باشد
```

### ✅ فعال کردن Debug Mode
در `main.py`:
```python
import logging
logging.basicConfig(level=logging.DEBUG)
```
